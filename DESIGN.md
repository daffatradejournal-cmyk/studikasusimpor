# shopee.com — Design System Brief
> Design source of truth for PasarTembilahan

## Context
- Source: https://shopee.com
- Page title: shopee.com
- Implementation Target: PasarTembilahan (Marketplace & Rantai Distribusi Komoditas UMKM Indragiri Hilir - UNISI)

## Design Tokens

### Primary / Brand Colors
- Primary Shopee Orange: `#EE4D2D`
- Danger / Discount Red: `#D0011B`
- Rating / Gold Star / Coin: `#FFCE3D`
- Teal / Free Shipping / Mall: `#00BFA5`
- Trust / Link Blue: `#066BC8`
- Primary Hover: `#F05D40`
- Primary Active / Dark: `#E2492B`
- Soft Orange Tint / Border: `#FACAC0`

### Neutral Colors
- White: `#FFFFFF`
- Black: `#000000`
- Page Background: `#F5F5F5`
- Card Light Background: `#FAFAFA`
- Muted Text Dark: `#555555`
- Subtext: `#5A5A5A`
- Deep Text / Heading: `#222222`
- Subtle Light: `#FBFBFB`
- Border: `#CCCCCC`
- Divider / Section: `#F8F8F8`

### Typography Scale
Fonts: `Roboto`, `Titillium Web`, sans-serif
- Headings: 32px (h1), 20px (h2), 16px (h3)
- Body: 14px (normal), 12px (small labels / metadata), 10px (tiny badges)

### Radii
- Badge / Input / Button Radius: `2px` (`.125rem`)
- Small Container Radius: `3px`
- Card / Modal Radius: `4px`
